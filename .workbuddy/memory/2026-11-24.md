## GET /prompts/{prompt_id} 补 404

- `app/api/v1/prompts.py`：`get_prompt_detail` 捕获 `KeyError` 抛 `HTTPException(404)`；区分两种情况——prompt_id 不存在 → `Prompt 不存在：xxx`；prompt_id 存在但版本不存在 → `Prompt 版本不存在：rag_qa@v9，可用版本：v1, v2`。
- 修了 `app/core/exception_handlers.py` 的既有 bug：`logger.warning(f"...", f"...")` 两个位置参数会被 logging 当成 `%` 格式化参数，导致每次 404/异常都打印 "Logging error: not all arguments converted"。改成单个 f-string（app_exception、http_exception 两处）。

## 踩坑记录

- `scripts/` 下的脚本没有 `sys.path` 处理，直接 `python scripts/x.py` 会 `ModuleNotFoundError: app`；需脚本内 `sys.path.insert(0, parent.parent)`，或改用 `python -m scripts.x`。
- 脚本里把 `app.llm.factory` 放在函数内延迟导入，离线模式就不依赖 LLM 配置。


- `renderer.py` 用 `str.format`，模板里字面量花括号必须写成 `{{ }}`，否则渲染直接崩；测试用 `extract_variables()` 做占位符一致性校验可同时抓这个问题。
- `registry.find_by_scenario(GENERAL_CHAT, "v1")` 返回首个注册项（`general_chat`），所以简历 Prompt 必须用 `render_by_prompt_id` / `registry.get` 取，不能走 scenario 查找。
